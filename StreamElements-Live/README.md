# Подключение к GitHub Pages

В существующем Custom Widget замените HTML, CSS, JS содержимым одноимённых файлов этой папки. Оставьте текущие FIELDS и DATA: настройки звука и текста сохранятся. Изображения теперь берутся с Pages, поэтому поля загрузки картинок не используются.

Размер виджета: 1200 × 600. Нажмите Done → Save. Проверьте кнопку тестового фолловера и Emulate → Follower event. Overlay URL в OBS остаётся прежним.

После изменения кода в GitHub дождитесь успешного Deploy Dragon Widget to GitHub Pages, затем обновите предпросмотр или источник браузера OBS (Обновить кэш текущей страницы). Открытый overlay сам не перезагружается посреди трансляции. Новые поля настроек требуют обновления FIELDS вручную.

Страница https://xel92.github.io/my-first-project/ должна быть доступна. Если iframe пуст, проверьте успешность Pages и ограничения встраивания/сети. Звук требует разрешённого воспроизведения в браузере и ненулевой громкости в микшере OBS.
