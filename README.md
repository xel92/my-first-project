# Dragon Follower Alert

Анимированный браузерный виджет для уведомлений о новых фолловерах Twitch. Дракон дышит во сне, просыпается при событии, показывает никнейм в облачке пять секунд и плавно засыпает.

## Предпросмотр

Запустите локальный сервер из корня проекта:

```bash
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Кнопка «Новый фолловер» запускает тестовую анимацию. Для прозрачного режима OBS используйте `http://localhost:4173/?overlay=1`.

## StreamElements

Файл `app.js` принимает стандартное событие `onEventReceived` с типом `follower-latest`. При нескольких событиях никнеймы ставятся в очередь и показываются последовательно.
